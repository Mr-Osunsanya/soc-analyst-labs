# Day 14 -File Integrity Monitoring (AIDE)

## Objective
Detect unauthorized file changes on the system

## Tool
AIDE(Advanced Intrusion Detection Environment)

## Activities 
- Installed the AIDE
- Created a baseline database
- Performed an integrity check
- Simulated a file modification
- Detected changes

## Analysis
- AIDE detects added, modified, and removed files
- Useful for the detection of malware and the tampering of system

## Conclusion
System can now detect unauthorized file changes effectively.
