## Day 11 - TCP Connection ANALYSIS (WIRESHARK)

## Objective 
Analze TCP connections and understand how devices communicate over a network.

## TOOL
Wireshark

## Activities
- Captured live network traffic
- Filtered TCP packets
- Analzed TCP flags
- Follwed TCP streams

## KEY CONCEPTS
- SYN: Start connection 
- SYN-ACK: Server response
- ACK: Connection confirmed
- PSH: Data transfer
- FIN: Normal close
- RST: Rejected connection

## ANALYSIS
- Normal traffic follows full handshake
- Failed traffic shows RST responses

## COMMUNICATION
Learned how to interpet network connections and identify successful vs failed communication.
