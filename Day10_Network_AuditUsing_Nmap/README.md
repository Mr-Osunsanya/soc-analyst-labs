# DAY 21 - Network Audit with Nmap

## Objective
Scan sysytem to identify ports, services, and OS.

## Tool
Nmap

## Commands Used
nmap -sS -sV -O localhost

## Findings
- Discoverded open ports
- Identified running services
- Detected OS information

## Analysis
- Open ports expose services to attack
- Services versions may contain vulnerabilities

## Conclusion
System successful audited for exposed services and potential risks.
